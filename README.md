# Prototipo HTML del calculador de préstamos

Abre `index.html` en un navegador. No requiere instalaciones ni servidor.

Ocho pantallas: acceso, registro, simulador, resultados con amortización, historial, comparador, confirmación de eliminación y acerca de.

Solo HTML: no contiene CSS, JavaScript, conexión a base de datos ni operaciones funcionales. Los botones están deshabilitados; los enlaces permiten recorrer el prototipo. Los datos son ilustrativos y los campos no se transfieren entre páginas.

Para respetar la presentación en blanco y negro sin CSS se usan atributos de presentación HTML heredados en el cuerpo y las tablas. Son adecuados para este boceto, aunque están obsoletos en HTML moderno. La apariencia de los controles nativos depende del navegador y del sistema.

Este prototipo sirve como referencia de pantallas para la futura aplicación de escritorio C++ / Qt / MySQL.
